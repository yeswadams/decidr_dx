# Your first change

Install dependencies with `pnpm install`, start the relevant app with `pnpm --filter <name> dev`, and make one focused change. For a package change, check the workspace's exported entry point and add a focused Vitest test for new behavior. Run `pnpm format:check`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build`. Update documentation if the change affects a boundary or contributor workflow, then submit a pull request using the template.
