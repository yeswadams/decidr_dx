# Security policy

Decidr is an early foundation and is not ready to run untrusted workloads. The runner does not execute submitted code.

Please do not report suspected vulnerabilities in public issues. Report them privately to the repository maintainers through the private vulnerability reporting feature on the hosting platform, if available. Include affected components, impact, and steps to reproduce. Do not include real secrets or sensitive user data in reports.

Supported-version and response-time commitments have not yet been established.
